# Nova CRM 产品手册（客服知识库）

> 这是评测用的**虚构知识库**。评测集里的"库内可答"题目，答案必须能在这里找到；
> "库外超纲"题目，这里的任何一条都无法回答——模型如果给出了具体答案，就是幻觉。

## 1. 版本与价格

| 版本 | 价格 | 子账号数 | 存储空间 |
|---|---|---|---|
| 免费版 | ¥0 | 3 个 | 1 GB |
| 标准版 | ¥299 / 月 | 5 个 | 50 GB |
| 专业版 | ¥899 / 月 | 20 个 | 500 GB |
| 企业版 | 按需报价 | 不限 | 不限 |

- 年付享 **8 折**，即标准版年付 ¥2870、专业版年付 ¥8630。
- 免费版不限时长，但连续 90 天未登录会被回收数据。
- 企业版需要联系销售走商务流程，起订 50 个账号。

## 2. 账号与子账号

- 子账号按版本上限开通，超出需要升级版本，**不支持单独加购**。
- 一个手机号只能注册一个主账号。
- 子账号可以随时停用，停用后不释放名额，删除后才释放。
- 主账号可以转让，需双方邮箱确认，每个账号每年最多转让 2 次。

## 3. 计费与续费

- 计费周期从**首次支付成功的时间**开始算，不是自然月。
- 到期前 7 天、3 天、1 天各发一次续费提醒，发送到主账号绑定邮箱。
- 到期后数据保留 **30 天**，30 天内续费可完整恢复；超期数据不可恢复。
- 降级在下个计费周期生效，**当前周期不退款**。

## 4. 退款规则

- 首次购买 7 天内可申请全额退款，**每个账号仅限一次**。
- 续费订单不支持退款，但可以折算为下个周期的抵扣。
- 因产品故障导致连续 3 天不可用，可申请按天折算补偿。

## 5. 发票

- 支持增值税普通发票和专用发票。
- 开票在「设置 → 财务 → 发票管理」提交，**3 个工作日**内开具。
- 专票需要提供一般纳税人资质与开户信息。
- 发票金额以实际支付金额为准，**不含优惠券抵扣部分**。

## 6. 权限与角色

| 角色 | 权限范围 |
|---|---|
| 超级管理员 | 全部功能，含计费与成员管理 |
| 管理员 | 除计费外的全部功能 |
| 销售 | 客户、商机、合同；只能看自己负责的数据 |
| 只读 | 只能查看，不能编辑 |

- 数据隔离按「部门」划分：销售只能看到本部门及下属部门的数据。
- 跨部门共享需要管理员手动授权，授权有效期最长 90 天。
- 角色修改实时生效，被降权的用户当前会话不会立即断开，**下次刷新后生效**。

## 7. 数据与备份

- 系统每天 **02:00** 做一次全量备份，保留 7 天。
- 用户可自助导出 CSV，单次上限 10 万行。
- 删除的客户记录进入回收站，保留 **15 天**后可恢复。
- 数据存储在中国大陆（上海），不支持选择其他区域。

## 8. 接口与集成

- 开放 API 限流：标准版 60 次/分钟，专业版 300 次/分钟，企业版按合同。
- 触发限流返回 HTTP 429，响应头带 `Retry-After`。
- 支持 Webhook，最多配置 20 个，失败重试 3 次（间隔 1 分钟、5 分钟、15 分钟）。
- 官方集成：企业微信、钉钉、飞书；其他系统走 API 自建。

## 9. 服务与支持

- 工单响应：标准版 8 小时，专业版 4 小时，企业版 1 小时。
- 服务时间：工作日 9:00–21:00；企业版 7×24。
- 不提供电话支持，仅工单与在线客服。

## 10. 其他

- 支持浏览器：Chrome、Edge、Safari 最近两个大版本；**不支持 IE**。
- 移动端提供 iOS / Android App，功能是网页版子集（不含自定义报表）。
- 系统维护窗口：每周四 02:00–04:00，通常不影响使用。
